3. Wi-Fi access points

Open networks are the project default. Choose WPA2 / WPA2+WPA3 to secure them. Country code and TX power follow the device and regulatory limits; they are not overridden.

4. Upstream Wi-Fi

Repeater only: true Layer 2 if the upstream AP supports WDS; otherwise leave off to use relayd.

Scanning briefly interrupts Wi-Fi clients on that radio. Scan results for the radio you are connected through may disconnect you.

4. Router options

PPPoE packages are not included in this image (flash size). Install ppp + ppp-mod-pppoe with opkg first.
